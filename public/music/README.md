# Background Music - Girlfriend's Day Web App

The website plays **"Until I Found You" by Stephen Sanchez**.

### How Audio Playback Works:
1. **Local MP3 (Recommended for offline / direct play):**
   Place your MP3 file named `until-i-found-you.mp3` inside this `public/music/` directory (`public/music/until-i-found-you.mp3`).

2. **Automatic Online Fallback:**
   If no local `until-i-found-you.mp3` is found in `public/music/`, the website automatically streams the official audio for **Until I Found You - Stephen Sanchez** via YouTube background player.
